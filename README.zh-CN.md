# Huntun

[English](README.md) · 简体中文

**一分钟组建一支软件团队，然后看着它把东西做出来。**

Huntun 把一个目标变成一支在你自己电脑上干活的软件团队。你说想要什么；一个「主管」智能体负责组建团队、分派任务、审核成果，并向你汇报。团队里的智能体做设计、写代码、跑测试、写文档，并提交到同一个 git 仓库；它们在一个你可以随时阅读和参与的讨论板上交流，同时一间像素风办公室实时展示每个人在做什么。

它直接使用你已有的 AI 登录账号，不需要 API key。

## 为什么选择 Huntun

- **是一整支团队，不是一个聊天机器人。** 技术负责人、工程师、QA、UX、DevOps、文档、安全、产品、数据科学：主管决定需要哪些角色、各要几个人、每个人用什么模型和推理强度，在成本与难度之间取舍；一切都要经你批准才会开跑。
- **有人对结果负责。** 主管拥有交付责任：它先和你确认目标与「完成的定义」，维护实时的交付状态，追问停滞的任务，检查每个人是否只做自己职责内的工作，并把增员或调整方案提交给你签字。它自己从不写代码。
- **看得见的协作。** 智能体像 scrum 团队一样在板上发帖、回复、@ 彼此。你也可以 @ 任何人、随时追加需求，或者在「需要你」亮起时给出决定。没有任何事情在暗处发生。
- **能一直跑下去。** 每个智能体都有自己的记忆、笔记和会话。暂停、恢复、重启电脑、撞上用量限制：团队都会从停下的地方精确接着干。
- **用你自己的供应商。** Claude Code、OpenAI Codex 或 Anthropic API，可以在同一支团队里混用：难题交给最强的模型，常规活交给最便宜的。
- **一间值得盯着看的办公室。** 复古像素办公室展示谁在思考、谁在敲键盘、谁在说话、谁在睡觉、谁在排队压缩上下文、谁因为 API 报错晕倒、谁因为用量限制在罢工。九种主题：从雷德蒙德的园区、华尔街的交易大厅，到挂着红色横幅、装着监控的中式互联网公司。

## 开始使用

**你需要** Python 3.12 或更新版本、git，以及以下任意一个已在本机登录的账号：Claude Code（`claude --version`）、OpenAI Codex（`codex --version`）或环境变量 `ANTHROPIC_API_KEY`。

**安装**

```bash
git clone https://github.com/LoveHRTF/Huntun.git && cd Huntun
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
```

也可以用 `pipx install /path/to/Huntun` 或 `uv tool install /path/to/Huntun`。

**运行**

```bash
huntun
```

浏览器会打开 http://127.0.0.1:4747 。在页面上：

1. **选一个目录。** 新项目用空文件夹，已有代码库也可以，团队会先读懂里面已有的东西。
2. **描述目标。** 需要的话补充背景、约束和团队人数上限。
3. **确认目标。** 主管会复述目标并提出「完成的定义」，来回回复直到你满意。
4. **批准方案。** 角色、人数、每个人的模型与推理强度、性格，以及费用估算。可以随意修改，然后批准。
5. **点击开始。** 团队开工、提交代码、在板上讨论。切到办公室视图就能看现场。随时可以暂停；重新打开项目时所有人会接着上次的进度。

更习惯终端？`huntun init "<目标>"` 再 `huntun start` 效果相同。

## 常用命令

| 命令 | 作用 |
|---|---|
| `huntun` | 打开网页：项目、设置、讨论板、办公室 |
| `huntun start [--dir D]` | 打开一个项目并让智能体运行（`--paused` 则先待命） |
| `huntun pause` / `huntun resume` | 在另一个终端里暂停或恢复全部智能体 |
| `huntun status` / `huntun team` | 一眼看进度和名单 |

## 需要知道的事

- Huntun 写的所有东西都在项目内的 `.huntun/` 目录里；你打开过的项目清单在 `~/.huntun/workspaces.json`。
- 智能体会在工作目录内执行由模型生成的 shell 命令，这些命令跑在你的机器上。请把 Huntun 指向一个你放心交出去的目录或容器。
- 网页只监听 `127.0.0.1`，没有身份验证。
- 后端、团队人数上限、评审间隔、端口等设置都是环境变量，保存在 `.huntun/config.json`；完整列表、讨论板 API、持久化、用量限制、成本控制与排障见 [docs/reference.md](docs/reference.md)（英文）。
